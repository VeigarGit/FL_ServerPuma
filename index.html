Quick start / MNISTbash
# Get the code and environment
$ git clone https://github.com/VeigarGit/FL_ServerPuma.git
$ cd FL_ServerPuma
$ uv sync

# Prepare client data
$ uv run python src/dataset/generate_MNIST.py noniid - dir

# Run a small FedAvg baseline
$ cd src/system
$ bash run.sh --clients 2 --rounds 5 --prune 0 --ala 1

Requires uv and tmux. See the documentation for setup and model-specific configuration.
